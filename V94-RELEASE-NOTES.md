# Iggy Meadow v94 — 24-step Meadow Chrome Visual Sprint

This sprint is based on the working v70 launch candidate. The user specifically asked for the menus and headers to stop looking artless, so this release concentrates on the visual chrome that is present on almost every screen rather than adding new gameplay systems.

## 24 completed proceedments

1. Replaced the old flat site header with a botanical Meadow masthead.
2. Added a proper Iggy Meadow wordmark plaque and tagline treatment.
3. Added the premium fawn Iggy portrait to the account area.
4. Rebuilt Iggy / Seed / Bone / Streak counters as illustrated resource tiles.
5. Integrated save status into the player plaque instead of a loose utility pill.
6. Rebuilt achievements, leaderboard, notifications, admin, profile and sign-out controls as compact rosette buttons.
7. Replaced the flat primary nav row with eight framed destination cards.
8. Added active-tab visual ribbons and section-specific pastel treatments.
9. Added a full-width illustrated chapter ribbon under the menu.
10. Made the chapter ribbon art change with the current destination.
11. Restored kennel-income collection as a styled ticket inside the chapter ribbon.
12. Rebuilt quick navigation as an integrated Meadow trail rather than a second plain nav bar.
13. Rebuilt the status ticker as a Meadow Gazette ribbon.
14. Replaced the old procedural SVG storybook headers with actual launch artwork.
15. Added botanical paw/flower ornamentation to chapter banners.
16. Rebuilt generic section titles into mini illustrated plaques.
17. Unified Shop, Profile, Collection, Bramblewick, Atlas and Toy subtabs into one premium visual language.
18. Restyled kennel, wardrobe and explore toolbars to match the site chrome.
19. Reworked primary, secondary and ghost buttons to use the same blush/sage/gold system.
20. Rebuilt modal chrome so popups look like part of Iggy Meadow rather than browser UI.
21. Upgraded collection, world-map and woods local headers to the same premium treatment.
22. Added tablet-specific masthead/nav composition so the new chrome stays usable on smaller screens.
23. Added mobile-specific resource, navigation, quick-trail and chapter layouts.
24. Added consistent keyboard focus styling and reduced-motion handling for the new UI.

## Scope / safety
- No database changes.
- No save-format changes.
- The 14-Iggy limit remains intact.
- Special Dog Bones remain intact.
- Existing premium art from v70 is reused; this release focuses on integrating it into the UI chrome.
- `.env.local` is intentionally excluded from the package.
