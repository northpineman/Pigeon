# Iggy Meadow v32 — Meadow Portal Era

This release pushes the presentation toward a colorful, information-rich classic virtual-pet portal while keeping Iggy Meadow original.

## Visual changes
- New three-column Meadow Portal dashboard on the home page.
- Eight colorful destination tiles for core systems.
- Player card, wallet, quick links, Meadow News, postcard/world teaser, daily status, seasonal and mystery teasers.
- Site shell redesigned with a compact early-web game portal feel: framed header, bright utility strip, chunky icon navigation, secondary quick links, and warmer content chrome.
- Home, cards, buttons, banners, shops and other major surfaces receive tighter illustrated portal framing.
- Responsive layouts collapse cleanly on tablets and phones.

## Safety / compatibility
- No database changes.
- No save-schema changes.
- Existing Supabase integration remains unchanged.
- Existing v31 visual systems are preserved.
