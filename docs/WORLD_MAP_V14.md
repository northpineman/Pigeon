# Iggy Meadow World Map — v14

The world map is now a first-class destination system. It uses an additive region catalog so new districts can be added without changing player-save schema.

## Current regions
- Meadow Heart — home
- Whispering Woods — exploration
- Kingdom of Bramblewick — medieval district foundation
- Frostpeak — seasonal winter district
- Fall Grove — seasonal autumn district
- Meadow Market — shops
- Arcade Lane — games
- Moonwater Coast — future
- Sunpetal Fields — future

## Direction
Each region is intended to grow into a destination with its own NPCs, shops, quests, collectibles, activities, stories, and seasonal content. The map intentionally separates the world layer from individual feature tabs so the game can expand without becoming a collection of disconnected screens.
