# Iggy Meadow v33 — Classic Portal Depth Pass

Built on v32, this pass adds more visual density and place identity so the game feels like a living virtual-pet portal rather than a modern dashboard.

- New Meadow Today ticker under the main navigation.
- Willow Kennels now resembles a row of cozy pet rooms with garden windows.
- Adoption House uses brighter storefront/adoption-window presentation.
- Market item cards feel more like individual shop shelves and stalls.
- Great Meadow atlas has a stronger framed-paper map treatment.
- Storybook banners, cards, buttons, and page chrome tightened for a classic pet-site feel.
- Responsive behavior retained.

No database or save-format changes.
